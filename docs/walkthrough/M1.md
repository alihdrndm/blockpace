# M1 walkthrough: the calculation library

## What was built
`packages/core` now contains the whole domain: Zod schemas for every input and output, exact integer money maths, and three functions. `evaluate` turns a block and its pickup snapshots into today's attrition bill. `forecast` projects pickup to the cutoff date. `riskLevel` turns both into `met`, `on_track`, `at_risk` or `liable`. Nothing reads the clock, the network or the database: "today" is always a parameter.

## Design decisions
1. **BigInt for every room and money calculation.** Floating point cannot represent most cents exactly, so `money.ts` converts percentages to whole basis points (12.5% becomes 1250) and rounds money exactly once at the end of each formula. Results only become normal numbers at the very end, and the code throws if one would lose precision.
2. **One formula, two uses.** `calc.ts` holds the attrition arithmetic. `evaluate` feeds it today's pickup and `forecast` feeds it projected pickup, so the two can never drift apart.
3. **Schemas are the rules.** Night rules (consecutive dates, 1 to 60 nights, cutoff not after the first night) live in `model.ts`. The API in M3 will reuse them rather than re-write them.
